# BOOKNook
Sovelluksen keskeiset toiminnot:
- Käyttäjätunnuksen luominen, kirjautuminen ja uloskirjautuminen.
- Omien kirja-ilmoitusten lisääminen, muokkaaminen ja poistaminen.
- Kirjojen selaaminen ja etsiminen.
- Kirjojen luokittelu genren, kielen ja kunnon perusteella.
- Käyttäjäprofiilit, jotka sisältävät tilastoja ja käyttäjän omat kirja-ilmoitukset.
- Osto- ja vaihtotarjousten tekeminen ja hallinta.
- Tarjousten hyväksyminen ja hylkääminen.
